# SPEC: AIエージェント紹介動画 共有仕様契約

このドキュメントは、AIエージェント(自律的にタスクを分解・実行するLLMエージェント、およびそれを組織的に運用するAI組織ハーネス orgh)を一般の開発者・ビジネス層に紹介する90秒前後の動画について、後続の全実装タスクが参照する**唯一の前提**である。ここに書かれていない判断が必要になった場合は、このSPEC.mdを更新してから作業すること。構成台本の実データは同ディレクトリの `scenes.json` を参照。

## 1. 動画仕様

| 項目 | 値 |
|---|---|
| 解像度 | 1920x1080 (16:9, フルHD) |
| フレームレート | 30fps |
| 想定尺 | 80〜120秒(scenes.jsonの合計durationSecがこの範囲に収まること) |
| 音声 | なし。ナレーション音声トラックは持たない。字幕(オンスクリーンテキスト)のみで内容が完結すること |

## 2. 実装スタック

- **Remotion (React)** を用いて実装する。
- プロジェクトルートは `docs/video/intro-ai-agent/` 直下とする。`package.json` ・ `remotion.config.ts` ・ `src/` 等はすべてこの配下に置き、リポジトリの他ディレクトリを一切汚さないこと。
- ディレクトリ構成の骨子:
  ```
  docs/video/intro-ai-agent/
    SPEC.md
    scenes.json
    assets/            # SVGアセット
    src/
      scenes/          # シーンごとのReactコンポーネント
  ```

## 3. 座標系とセーフエリア

- 原点は画面左上 (0, 0)。x は右方向、y は下方向に増加する。
- 外周 **96px** をセーフマージンとする。すべてのテキスト要素は、この内側(1920x1080のフレームなら x: 96〜1824, y: 96〜984の範囲)に収めること。
- 図形(SVGアセット等)はセーフマージンの外に一部かかっても良いが、可読性に関わる要素(テキスト・ラベル)は必ずセーフエリア内に収める。

## 4. カラーパレット(ダーク基調)

| 用途 | 名称 | HEX |
|---|---|---|
| 背景色(主) | Background Primary | `#0B0E14` |
| 背景色(副・パネル等) | Background Secondary | `#151A24` |
| 主要文字色 | Text Primary | `#F5F7FA` |
| アクセント色(主) | Accent Primary | `#4F8CFF` |
| アクセント色(副) | Accent Secondary | `#7CF29C` |
| 補助色(枠線・区切り) | Support Line | `#2A3242` |
| 補助色(弱文字) | Support Muted | `#8891A5` |

- すべてのSVGアセット・オンスクリーンテキストの配色は、上記HEX値をリテラルで指定すること(別カラーの追加や中間色の生成はしない)。

## 5. タイポグラフィ

| 用途 | フォントファミリ | サイズ |
|---|---|---|
| 見出し (headline) | `"Hiragino Sans", "Noto Sans JP", system-ui, sans-serif` | 72px |
| 本文・字幕 (sub / narration) | `"Hiragino Sans", "Noto Sans JP", system-ui, sans-serif` | 36px |

- 見出し・本文ともにOS標準のsans-serifへのフォールバックを必ず含める。
- 外部フォントファイル(Webフォント埋め込み等)の参照は禁止。OSにインストール済みのフォントのみで完結させる。

## 6. ファイル命名規則

- **シーンID**: `s01` 〜 `s0N` のゼロ埋め2桁(例: `s01`, `s02`, ... `s08`)。
- **SVGアセット**: `assets/<sceneId>-<用途>.svg` (例: `assets/s01-hero.svg`, `assets/s03-diagram.svg`)。
- **シーンコンポーネント**: `src/scenes/<SceneId>.tsx` (SceneIdは先頭大文字化、例: `src/scenes/S01.tsx`)。

## 7. SVGアセット規約

- `viewBox="0 0 1280 720"` を固定で用いる。
- 数値は単位なし(`px`等のサフィックスを付けない)。
- `width` / `height` 属性はSVGルート要素に付けない(viewBoxのみでスケーリングする)。
- 色は本SPEC.mdの「4. カラーパレット」に列挙したHEX値をリテラルで指定する(新規色を追加しない)。
- 外部フォント参照は禁止。文字を含める場合はpath化せず `<text>` 要素 + `font-family="system-ui, sans-serif"` 等のフォールバック指定で表現してよい。

## 8. 構成方針(参考)

`scenes.json` の構成は以下の流れを含めること:

1. AIエージェントとは何か
2. 従来のチャットAIとの違い(自律的な計画・ツール実行・検証ループ)
3. 複数エージェントの分業と統合
4. 何が嬉しいのか(具体的なユースケース)
5. まとめ・次の一歩

各シーンの詳細内容(テキスト・ナレーション・アセット指示)は `scenes.json` を正とする。
