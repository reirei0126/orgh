AI AGENT ORCHESTRATION / 実話ベース

寝る前にメモを書いた。
朝、チームの仕事が終わっていた。

orghは、ふつうのメモを仕事のミッションへ変えるエージェント・オーケストレーションハーネス。 AIが計画し、並列で手を動かし、別のAIが検品して差し戻す。 人間の仕事は、意図を書くことと、できあがった結果を検収することになる。

やったこと
「これ、お願い」とメモを書く
→
次にやったこと
レビュー済みの結果を読む

読者の痛み

AIを雇ったのに、毎晩「次はこれ」と呼び戻している。

Claude CodeもCodexも、個々の実力はもう十分すぎるほど強い。それでも結局、指示を書き、待ち、差分を読み、「ここ直して」と呼び戻す ——エージェント同士のバトンを手渡しているのは人間自身だ。賢い道具が増えるほど、自分の「監督業」まで増えていた。

会議の合間に指示を書き、深夜にもう一度差分を見にいく。ツールは並列に動けるのに、レビューして・差し戻して・もう一度、を回しているのは 結局いつも自分ひとり。ボトルネックは、いつのまにか自分だった。

また差分を読まなきゃ
「ここ直して」をもう一回言う
待ってる間、他の作業が止まる
結局、自分がボトルネック

orghのある日常

翌朝、スマホのObsidianに「レビュー済み」が届く。

翌朝 / RESULTS NOTE
ミッション結果ノート status: done
task A ✓ pass
task B ✓ pass
次のメモ 「このまま公開準備を進めて」

夜投げたミッションの結果ノートが届いている。タップして開き、レビュー済みの差分を読み、問題なければそれで検収は終わり。 気になる点があれば、そのノートに一言書き足すだけで、次の指示になる。

結果ノートは進行のたびに全文が更新され、成果物もそこにリンクされる。ターミナルを開く必要すらない。 スマホでノートを開いた時間が、そのまま検収の時間になる。

根拠: README.md「vault完結のフィードバック(orgh watch)」— 結果ノートはミッション進行のたびに全文更新される仕組みが実装済み

安心

BUDGET
GUARD

予算ガード

ミッション/タスクごとにUSD上限を設定でき、超過すると未着手タスクは止まる。上げて再開すれば続きから走る。

根拠: README.md「予算ガード」、上の証拠レシートの超過→resume実測

APPROVED
ONLY

自己改変は人間承認が必須

orgh自身を書き換えるタスクは自動実行されず停止する。続行できるのは人間の承認コマンドのみで、設定でも無効化できない。

根拠: README.md「統治線」、証拠レシートの承認ファイル実測
